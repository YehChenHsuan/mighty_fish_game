## 🎮 遊戲簡介與核心特色

《Mighty Fish 海底英語大冒險》是專為 **ALICE ESL Phonics P1** 兒童美語設計的 3D 沉浸式水下闖關學習遊戲。靈感源自經典 3D Mighty Fish 物理動力學，孩童化身為靈巧的橘紅小魚在深邃蔚藍的珊瑚礁海底暢遊，游向迎面而來的正確答案小魚！

### 🌟 三大特色學習題庫：
1. **🌊 完整句型問答 (Q&A Mode - 課本第 10、26 頁)**：
   - 聆聽真人完整提問（如：*Can the fish swim?*、*Can the rabbit soar?*）。
   - 迎面游來攜帶不同回答字卡的小魚群（如 *Yes, it can.* / *No, it can't.*），辨析語法並游向正解小魚！
2. **🐾 動物動作配對 (Action Match - 課本第 06-07 頁)**：
   - 觀察動物特徵與生活習性，配對 *hop*, *run*, *swim*, *climb*, *jump*, *fly* 等核心動詞。
3. **🔤 自然發音首字母瘋狂尋寶 (Phonics Catch)**：
   - 鎖定核心首字母發音（如 [Ff], [Dd], [Hh], [Jj], [Kk], [Rr] 等），尋找吻合發音之單字魚群。

## 🕹️ 操作方式與自適應支援

- **操控模式**：
  - **🖱️ 滑鼠游標**：移動滑鼠牽引小魚游動。游向右側加速游動衝刺，靠左減速等待思考，上下操控俯仰高度。
  - **📱 平板觸控**：手指在螢幕上滑動，小魚平滑跟隨指尖游動。
  - **📷 AI 食指追蹤**：啟動攝影機，免穿戴任何設備，伸出食指即可隔空精準操控小魚！
- **自適應難度**：內建 0.7× 慢速、1.0× 標準、1.3× 進階與 1.6× 極速倍率，並支援 30s ~ 90s 與無限時間模式。
